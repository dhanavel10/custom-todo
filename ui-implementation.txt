I want you to completely redesign the UI/UX of my existing Productivity Inbox application.

This is not a simple CSS refresh. I want a significant visual transformation across the ENTIRE application, including the React Web application and Flutter Mobile application.

Your goal is to make this application look like a premium, professionally designed productivity product that could compete with applications such as Linear, Things 3, Sunsama, Akiflow, and Motion.

The final result must have its own distinctive visual identity rather than copying any of these applications.

# 1. FIRST: UNDERSTAND THE EXISTING APPLICATION

Before making changes:

1. Inspect the complete project structure.
2. Understand the existing React application inside `client/`.
3. Understand the existing Flutter application inside `mobile/`.
4. Identify all existing pages, shared components, modals, dialogs, navigation elements, and theme implementations.
5. Understand the existing API integrations, state management, database models, and business logic.
6. Identify reusable components and existing design inconsistencies.

Do not immediately start changing random CSS files.

First understand how the existing application works so the redesign does not break any functionality.

IMPORTANT:
- Preserve all existing functionality.
- Do not remove working features.
- Do not change backend APIs or database schemas unless absolutely necessary.
- Do not replace existing business logic with mock implementations.
- Do not introduce dummy tasks or hardcoded dashboard statistics.
- Use actual application data.
- Preserve existing navigation and workflows.
- Do not break authentication, task management, AI classification, notifications, reminders, or persistence.

I don't want another generic Bootstrap dashboard or ordinary admin panel.

Create a unique design language for my Productivity Inbox application.

Design inspiration:
- Linear: refined interface and excellent information hierarchy.
- Things 3: beautiful task organization.
- Sunsama: daily planning experience.
- Motion: intelligent scheduling concepts.
- Notion: clean typography and structured content.
- Raycast: premium dark interface and keyboard interactions.

Do not copy their designs. Take inspiration from their design quality and create an original visual identity.

### Visual direction

Create a premium productivity workspace using:

- Deep graphite and midnight backgrounds for dark mode.
- Warm off-white and subtle neutral backgrounds for light mode.
- Electric violet / indigo as the primary accent.
- Carefully selected teal, amber, coral, and green for contextual states.
- Beautiful typography with strong hierarchy.
- Generous spacing and consistent alignment.
- Subtle borders and layered surfaces.
- Carefully designed shadows.
- Smooth transitions and micro-interactions.
- Beautiful icons instead of excessive text labels.

Avoid:
- Generic dashboard templates.
- Excessive gradients.
- Excessive glassmorphism.
- Too many rounded cards.
- Excessive borders.
- Oversized headings.
- Unnecessary decorative elements.
- Random colors across different pages.
- Cluttered layouts.

The UI should feel sophisticated, focused, lightweight, and highly usable.

# 8. TECHNICAL IMPLEMENTATION RULES

### React

- Inspect and reuse the existing stack.
- Prefer reusable components.
- Use the existing routing architecture.
- Keep components modular.
- Maintain existing state management.
- Maintain API integration.
- Avoid unnecessary dependencies.
- Use CSS variables/design tokens or the existing styling system.
- Avoid massive single-file components.
- Ensure responsive behavior.

### Flutter

- Follow the existing project architecture.
- Create reusable widgets.
- Centralize design tokens.
- Use ThemeData consistently.
- Support light and dark themes.
- Use appropriate Flutter animations.
- Preserve existing state management and API integration.
- Avoid putting the entire UI inside large build methods.
- Ensure good widget performance.

### Both applications

Keep the design systems visually consistent.

Where possible, use matching:
- Colors.
- Typography.
- Spacing.
- Radius.
- Icons.
- Status indicators.
- Interaction patterns.

Do not force identical layouts across platforms.
